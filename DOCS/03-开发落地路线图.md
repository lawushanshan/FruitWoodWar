## M0：环境准备（第一步）

| 事项 | 说明 |
|---|---|
| 安装 Cocos Creator 3.8.x | 官网下载 Dashboard，装 3.8 最新稳定版（免费） |
| 学习资料 | Cocos 官方文档"新手入门"教程（做一遍官方 2D 小游戏示例） |
| TypeScript 基础 | 不用系统学，边做边查：变量/函数/类/接口 会这些就够 |
| 工程约定 | 游戏逻辑全部用 TS 写；数据配置用 JSON/表格驱动，改数值不改代码 |

> 为什么选 Cocos：一套代码导出 H5 + 微信小游戏 + 抖音小游戏，国内 H5 小游戏事实标准，中文资料最多。

## M1：灰盒原型（最关键的一步）

**目标：用最丑的方式验证"好不好玩"。** 全部用色块、圆点、文字，不写任何美术资源。

开发顺序（每一步都是可运行的小目标）：

1. **地图与移动**：一条路 + 一个方块沿路走（红方→蓝方）
2. **自动战斗**：红蓝方块相遇互相攻击，血条，打死变星星
3. **兵工厂与出兵**：点击地面建厂，每 20 秒自动出兵
4. **经济系统**：金币 UI、工资定时发放、击杀赏金
5. **水晶与胜负**：水晶血量、被打爆、胜利/失败结算画面
6. **AI 对手**：对面按简单脚本自动建厂
7. **数值接入**：把《02-数值设计表》做成 JSON 配置文件读入

**验收玩法**：自己玩 10 局，回答三个问题——
- 一局是不是 6 分钟左右？
- 有没有"想再来一局"的感觉？
- 三种流派（爆兵/铁壁/快攻）是否各有胜算？

> 如果不好玩，回来改设计文档，改完再做。**这一步花的时间最值。**

## M2：系统补全

| 任务 | 内容 |
|---|---|
| 三阵营 | 阵营选择界面，数值修正系数接入 |
| 兵工厂升级 | Lv2/Lv3、★标识、价格递增规则 |
| 战争学院/光环塔 | 解锁逻辑与全局 buff |
| 兵种克制 | 克制矩阵接入，命中显示伤害倍率 |
| 绝地反击 | 连败检测与工资加成 |
| AI 三档 | 简单/普通/困难行为树 |
| 关卡/难度选择 | 主菜单 → 选阵营 → 选难度 |
| 存档 | 本地保存最佳战绩（localStorage/平台存储） |
| 结算 | 星级、击杀数、用时统计 |

## M3：美术音效

| 任务 | 说明 |
|---|---|
| 美术规格 | Q 版卡通：兵种 15 个 + 建筑 8 种×3 阵营皮肤 + 水晶 3 种 + 地图 1 张 + UI 一套 |
| 获取途径 | ① 先用 kenney.nl / itch.io 的 CC0 免费素材拼占位 → ② 有预算再找美术定制或买素材包 |
| 动画 | 出兵弹跳、攻击前摇、死亡弹飞变星星（全龄化要求） |
| 音效 | 建造/出兵/击杀/金币/水晶爆炸，免费音效站：freesound.org |
| 打击感 | 伤害跳字、屏幕轻微震动（水晶受击）、击杀连击数 |

## M4：平台适配与上线

| 任务 | 说明 |
|---|---|
| 微信小游戏 | Cocos 构建导出 wechatgame 包 → 微信开发者工具调试 → 注册小游戏账号（个人主体可发，但需类目审核） |
| 抖音小游戏 | 同上，导出 bytedance-mini-game 包 |
| 性能优化 | 包体 <4MB 主包（首屏）、合图、对象池、控制同屏单位数 |
| 广告接入 | 激励视频：失败复活水晶 / 开局双倍工资 |
| 合规检查 | 无魔兽相关元素、适龄提示、隐私协议 |
| 测试 | 真机全机型测一遍（低端机 30 帧达标） |
