| 工具 | 用途 | 地址/说明 |

| 即梦 AI | 生成所有图片（主力） | jimeng.jianying.com，手机号登录，每天有免费积分 |

| 本工程 tools 目录 | 放原图 + 处理脚本 | 已建好 `tools/raw_art/` 子目录 |

**目录约定**（原图统一放这里，处理完自动进工程）：

```
tools/
  process_art.py        # 批量后处理脚本
  raw_art/              # 你从即梦下载的原图放这里
    units/              # 兵种 + 大本营（已抠图 PNG）
    buildings/          # 建筑（已抠图 PNG）
    ui/                 # UI 图标（已抠图 PNG）
    fx/                 # 特效贴图（已抠图 PNG）
    cards/              # 卡牌插画（后置，已抠图 PNG）
    map/                # 地图底图（JPG，不用抠）
```

**文件命名规范**（处理脚本按名字识别尺寸，务必遵守）：

| 类型 | 命名 | 示例 |
|---|---|---|
| 兵种 | `u_{阵营}_{定位}.png` | `u_fruit_tank.png` |
| 大本营 | `hq_{阵营}.png` | `hq_wood.png` |
| 建筑 | `b_{名称}.png` | `b_academy.png`、`b_factory_tank.png` |
| 地图 | `map_bg.jpg` | — |
| UI 图标 | `ico_{名称}.png` | `ico_coin.png` |
| 特效 | `fx_{名称}.png` | `fx_slash.png` |
| 卡牌 | `card_{阵营}_{id}.png` | `card_fruit_heal.png` |

阵营 id：`fruit`（水果）/ `wood`（绿木）/ `animal`（动物）。定位 id：`tank`/`ranged`/`aoe`/`rush`/`siege`。

## 2. 全局风格模板

> 所有提示词 = **全局头 + 主体描述 + 全局尾**。本指南后面每条提示词都已拼好完整版，直接复制即可；这里放模板是为了你自己改、补素材时不跑偏。

### 2.2 全局尾（按素材类型三选一）

**角色类**（兵种）：

```
，单个角色完整全身，侧面视角面朝右，角色居中占画面八成，纯绿色背景，
无文字，无水印，无地面阴影，无多余物体
```

**建筑类**（工厂/学院/塔/大本营）：

```
，单栋建筑完整可见，正视图，居中，纯绿色背景，无文字，无水印，无阴影，无多余物体
```

**图标类**（UI/特效）：

```
，单个物体居中，纯绿色背景，无文字，无水印，无阴影
```

> 为什么是"面朝右"？红方单位向右进攻；蓝方在代码里水平翻转（scaleX=-1）即可，不用生成两套图。
> 为什么是"纯绿色背景"？绿幕抠图原理，比白背景抠得干净（详见第 11 节）。

### 3.4 操作要点

1. 即梦 → 图片生成 → 粘贴提示词 → 比例选 **16:9**（一排 5 个角色）；
2. 每次生成 4 张，挑"五个角色都完整、风格统一"的；不满意就重掷或微调主体描述；
3. 定稿后**重命名为 `anchor_fruit.png` / `anchor_wood.png` / `anchor_animal.png`**，存到 `tools/raw_art/` 外的安全位置（它不进游戏，只当参考图）；
4. **验收**：三张放一起看——风格像同一个游戏？三个阵营一眼能区分？通过才进入下一步。

> 参考图用法：生成该阵营后续任何资产时，在即梦输入框找到「参考图」入口，上传对应全家福，参考强度拉到 85%~100%。

> 兜底机制：就算某张图忘了抠图（还是绿底）直接放进 `raw_art`，后处理脚本也会自动把接近纯绿（#00FF00）的背景像素去掉。但即梦智能抠图对复杂边缘更干净，**能抠还是先抠**。注意：脚本只认"纯绿"，白底/灰底图无法自动处理，会打印警告提醒你先抠图。

### 11.1 首选：即梦自带抠图

1. 打开即梦，找到已生成的图片 → 点「智能抠图」（或在图片编辑里）；
2. 自动去底 → 检查边缘 → 导出 PNG。

### 11.2 备选：醒图（免费 App）

导入 → 智能**抠图 → 自动识别主体 → 保存透明 PNG。

### 11.3 批量：Python rembg（素材多时再装）

```bash
pip install rembg onnxruntime
```

```python
from rembg import remove
from PIL import Image
img = Image.open("原图.png")
remove(img).save("抠图后.png")
```

### 11.4 绿边急救

- 轻微绿边：缩到接入尺寸（128px）后基本不可见，可先不管；
- 明显绿边：生成时追加"背景为纯绿色 #00FF00"（明确色号 AI 更听话）；抠图工具里把"容差"调大一档；
- 实在不行：醒图手动橡皮擦。

## 12. 批量后处理脚本使用

脚本已就位：`tools/process_art.py`。它做的事：**抠边 → 居中裁方 → 高质量缩放 → 按规范命名输出到 `assets/resources/art/`**。

### 12.1 一次性环境准备

```bash
# 装 Python 后执行（只需一次）
pip install pillow
```

### 12.2 日常使用

1. 从即梦下载 → 抠图 → 按**命名规范**放进 `tools/raw_art/` 对应子目录；
2. 双击运行或执行：

```bash
python tools/process_art.py
```

3. 输出位置：`assets/resources/art/units|buildings|ui|fx|cards|map/`，直接进 Cocos 工程；
4. 地图底图（JPG）放 `raw_art/map/map_bg.jpg`，脚本自动缩放并居中裁切成 1280×720。

### 12.3 脚本内置尺寸规则

| 分类 | 默认输出 | 特例 |
|---|---|---|
| units | 128×128 | 大本营 `hq_*` 192×192 |
| buildings | 128×128 | `b_academy` 144×144、`b_tower` 96×96 |
| ui | 96×96 | 面板 `ui_panel_*` 256×256 |
| fx | 96×96 | `fx_glow`/`fx_boom`/`fx_ring` 128×128 |
| map | 宽 1280 JPG | — |

另外：建筑图会**额外输出一份 96×96 副本到 ui/** 当建造栏图标（命名 `ico_build_*`），不用重复生成。

## 13. 放进 Cocos 工程

### 13.1 资源就位

后处理跑完后，`assets/resources/art/` 会有完整的分类目录。回到 Cocos Creator 编辑器会自动导入。

### 13.2 自动图集（合批，性能关键）

对每个分类目录：资源管理器右键目录 → **新建 → 自动图集配置（Auto Atlas）**：
- `units/`、`buildings/` 可以合并建一张（2048×2048 上限）；
- `ui/` 一张（1024）、`fx/` 一张（512）；
- 默认参数即可，MaxSize 按上面设置。

### 13.3 构建压缩设置（M3.5 时配置）

项目设置 → 压缩纹理 → 添加预设：小游戏平台 `ETC2 + ASTC + PNG`（引擎按设备自动挑）。单张图也可以在属性检查器单独覆盖。

### 13.4 代码接入（找我来改）

到这一步后把需求发我，改造集中在 `GameManager.ts`：

3. `onLoad` 预载图集 SpriteFrame 到 Map 缓存；

## 15. 常见问题急救

| 症状 | 急救 |
|---|---|
| 生成的角色风格和之前不一样了 | 检查是否挂了阵营全家福参考图；参考强度拉到 85%+ |
| 角色出了多个/多了背景杂物 | 提示词里"单个角色""无多余物体"没生效 → 重新生成，别硬修 |
| 憋不出满意的图 | 别死磕！同一提示词重掷 3~4 次挑最好的，AI 是抽卡 |
| 绿色角色和绿背景融了 | 把背景色改纯白生成，抠图用醒图智能抠（主体优先） |
| 免费积分用完 | 切豆包画图 / Leonardo（每天免费 150 张）轮着用 |
| 抠图边缘锯齿 | 后处理脚本缩放到 128 后大多消失；个别图手动擦 |
| AI 把"侧面视角"画成正面 | 提示词加"身体朝向右边，头部看向右边"；还是不行就凑合用正面图（游戏里不明显） |
| 想微调已定稿的图 | 用即梦的局部重绘，别整张重生成 |
