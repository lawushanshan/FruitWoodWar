- 重构 GameManager.ts：从 1012 行缩减到 ~230 行，只做生命周期编排 + 模块装配 + 事件路由

- Toast 直接展示引擎返回的 message 字段
- 建造栏价格按阵营/学院等级/科研层数动态刷新

四、本地最佳战绩存档（M4-9）
----------------------------------------
- 新增 core/save-system.ts：localStorage 存档，按阵营+难度维度记录最佳战绩
- 评判标准：星级 > 胜负 > 用时（胜利）/ 击杀（失败）
- 结算时自动保存，新纪录时 Toast 提示
- 仅保存序列化数据，不保存运行时对象引用
- 不导入 cc，可在 Node 环境运行

M5 美术、音效和性能 —— 2026-08-19
========================================

----------------------------------------
- 新增 presentation/node-pool.ts：通用节点对象池
- 按类型分池，避免频繁创建/销毁带来的 GC 压力
- 回收时重置位置/缩放/透明度，保证复用时状态干净

二、升级精灵工厂（M5-2）
----------------------------------------
- ColorSpriteFactory 支持 6 种形状：rect / circle / diamond / triangle / hexagon / star
- 每种形状带描边，视觉上更清晰
- 兵种形状映射：坦克=圆形、远程=菱形、AOE=星形、冲锋=三角形、攻城=矩形
- 建筑形状映射：兵工厂=方形、学院=六角形、光环塔=圆形、基地塔=三角形、水晶=六角形

----------------------------------------
- 新增 presentation/floating-text.ts：浮动文字系统
- 支持伤害数字（红）、金币获取（金）、治疗（绿）
- 自动上升 40px + 淡出，0.6~0.8 秒完成
- 使用对象池复用节点

四、死亡弹飞表现（M5-4）
----------------------------------------
- 新增 presentation/death-effect.ts：死亡弹飞动画

- 符合全龄化设计：弹飞 + 消散，无血腥
- 使用对象池复用节点

五、音效管理器（M5-7）

- 新增 presentation/audio-manager.ts：Web Audio API 合成音效

- 支持音量控制与静音开关
- 静默降级（无 AudioContext 时不影响游戏）

六、GameManager 集成（M5-8）
----------------------------------------
- 集成 FloatingText / DeathEffect / AudioManager
- 状态追踪检测：单位死亡→弹飞、金币变化→跳字、水晶受伤→伤害数字、击杀→音效
